# Daily Flow · 本地清单版

2026-09-16：界面和主要交互已从 Sunsama 风格改为参考滴答清单的三栏清单工作区。
本项目是独立的本地应用，不连接滴答清单账号，也不能声称已经复刻其所有会员功能。

## 启动与本地数据

```powershell
npm install
npm run dev
```

日常请固定使用 `http://localhost:5173/`。服务运行中可直接刷新，CSS 和组件修改由 Vite 更新。
5173 被占用时，启动会明确报错，不再自动切换到 5174 / 5175。请先使用已运行的同项目服务，或停止自己此前启动的服务。

**localhost 与 127.0.0.1、不同端口、不同浏览器拥有各自的数据。**
如果旧任务在别的地址，先在原地址打开并导出，再在新地址导入。不要清空浏览器存储。

```powershell
npm test
npm run build
```

生产产物位于 dist。`npm run preview` 在 localhost:4173 预览生产构建，仅用于验收；它不会读取 5173 的任务。
Node.js 24 环境已通过构建和测试。依赖版本已锁定。

## 已实现

- 浅灰侧边导航 / 蓝色选中态 / 中间任务行 / 右侧直接编辑。
- 收集箱、今天（包括过期未完成）、最近 7 天、全部、已完成、垃圾桶。
- 自建清单、任务归属、标签筛选、搜索、日期／优先级排序、列表／看板切换。
- 回车快速添加；识别 今天 / 明天 / 后天 / YYYY-MM-DD、HH:mm 和 #标签。并非完整自然语言解析器。
- 右侧编辑名称、描述、子任务、日期、开始时间、预计时长、四级优先级、日／周／月重复。
- 完成每日／每周／每月重复任务时生成下一次；重复点击完成不会重复生成。
- 垃圾桶可恢复任务，不做永久删除。
- 日／周／月日历、月份跳转、全天任务、双击空白创建。
- 日历中拖动移动任务；拖动下边缘修改时长；键盘上下键分别移动 15 分钟／调整 5 分钟。
- 时间重叠的任务并列显示并标注，不悄悄删除或移动用户指定的时间。
- 未指定时间的任务显示为全天。自动排程只有主动点击「安排全天任务」才执行，保留指定时间。
- 四象限：以四级优先级映射分区，支持拖动分区。
- 番茄专注：5 / 15 / 25 / 45 / 60 分钟，开始、暂停、重置、完成记录。切换应用模块仍继续计时。
- 习惯：创建、今日打卡／撤销、累计天数。
- 浅色／深色、JSON 导入校验、确认合并、JSON 导出。
- 手机底部导航、抽屉式清单导航、全屏详情；390px 布局已在浏览器检查。

## 数据兼容

旧版 `daily-flow-tasks` 在首次打开新版本时迁入 `daily-flow-v2`，原键保留。
旧日期、时长、完成状态和已保存的手动时间会保留。旧版首次自动生成的固定午餐/晚餐不继续凭空加入新日历。
迁移或读取错误会显示提示并阻止自动覆盖原始存储，可先导出原始数据。
导入会保留现有数据，并为新任务分配新 ID；同名清单合并；重复关系重新映射。

## 与滴答清单仍有差异

不包含：账号、云同步、共享协作、第三方日历订阅、微信服务、系统级推送／定位提醒、附件、完整 Markdown 编辑、AI／语音、倒数纪念日、年视图、多周视图、复杂重复规则、全部主题等。
看板目前按优先级分组；四象限使用简化映射；习惯统计为基础累计次数。
专注计时器需要页面保持打开，切换模块可继续；刷新或关闭页面会重置未完成的计时。
手机的布局已验证，尚未在实体 iPhone Safari 和 Android Chrome 上逐项验证触摸手势。
官方功能页公开文字已经核对，但其中产品示意图未加载，因此不声称逐像素完全一致。

## 代码入口

- src/App.tsx：应用导航与交互连接
- src/model.ts：数据模型、筛选、重复、导入校验、旧数据迁移
- src/repository.ts：本地读写与导出
- src/components/：清单行、详情、日历、日期选择、弹窗、专注和习惯
- src/scheduler.ts：保留的独立规则排程器
- src/index.css：统一样式，首行保留 Tailwind 入口

旧版未使用组件留在 src 中供回溯；新的 main.tsx 只挂载 App.tsx。
